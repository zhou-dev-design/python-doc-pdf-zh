**必须保持原目录层级**：```Doc/locales/zh\\\\\\\_CN/LC\\\\\\\_MESSAGES/├── about.po  bugs.po  glossary.po  license.po  sphinx.po   ← 根目录 9 个├── library/datetime.po ...                                ← 326 个├── reference/expressions.po ...                           ← 11 个├── c-api/object.po ...                                    ← 77 个├── tutorial/classes.po ...                                ← 17 个├── howto/logging.po ...                                   ← 29 个└── whatsnew/3.14.po ...                                   ← 25 个```层级错了或少了，对应页就**保留英文**（不报错，所以容易漏）。### 1.2 `python-docs-theme` 到底管什么（别误解）```python# Doc/conf.pyhtml\\\\\\\_theme = 'python\\\\\\\_docs\\\\\\\_theme'     # ← 只作用于 -b htmlhtml\\\\\\\_theme\\\\\\\_path = \\\\\\\['tools']latex\\\\\\\_engine = 'xelatex'             # ← 只作用于 -b latex```* `-b html` → 用 `python-docs-theme`，产出 docs.python.org 那个样子（左侧目录树 + 站内超链接）；* `-b latex` → 用 Sphinx 的 `sphinxmanual.cls` / `sphinxhowto.cls` + `sphinx.sty`，**与 theme 无关**。所以"PDF 用 python-theme"严格说做不到；**PDF 的官方样式来自 Sphinx 的 LaTeX 支持**。但 `python-docs-theme` 依然是必装依赖（见 `Doc/requirements.txt`），也是本方案 HTML 环节的主题。\---## 2\. 依赖清单（对齐 `Doc/requirements.txt`）CPython
