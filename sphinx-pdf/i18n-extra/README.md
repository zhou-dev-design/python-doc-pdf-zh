# i18n-extra —— 已降级为「发布源」，程序运行时**不读**这个目录

★ 2026-10-04 起，这两个 `.po` 的内容**已内嵌进 `gui/pdf_builder_gui.py`**
（`I18N_EXTRA` 字典）。**权威副本是主程序里那份**，本目录只是它的一个副本，
放在这里是为了「有个现成目录可以直接上传当发布源」。

## 程序实际用的那份在哪

步骤 3 每次运行都会把内置的那份**整份重写**到 **`<构建根>/i18n-extra/`**，
再用 `--extra` 铺进 `LC_MESSAGES`（只补缺口、幂等）。

```bash
# 看内置那份长什么样 / 重新导出一份（本目录就是这么来的）
python gui/pdf_builder_gui.py --tool extra-dump <某个目录>
```

## 想让「每次运行都单独取一份最新版」

在配置里填「补充译文地址」（或 `--i18n-extra-url`），三种源都认：

- `http(s)://…/manifest.json` → 清单文件 `{"builtins/index.po": "<文本>", …}`
- `http(s)://…/dir` → 目录前缀，按内置那份的相对路径逐个 GET
- `file://…` 或**本机目录路径** → 直接读该目录里的同名文件

把本目录上传到任意可访问的地方，再把 URL 填进去即可。
**取不到就回退内置那份，断网也能跑** —— 只是会警告一句。
